# Manual de Operação do Usuário: Inspetoria Escolar

Este manual fornece instruções práticas e ilustradas para a operação diária do sistema **Menu Solutions** pelos inspetores de alunos, garantindo a realização ágil da contagem matinal antes do horário limite das **07:30**.

---

## 1. Acesso ao Sistema (Tela de Login)

```
+-----------------------------------------------------------+
|                      MENU SOLUTIONS                       |
|           [ Ícone: Chapéu de Chef / Code Solutions ]      |
|                                                           |
|  Usuário / E-mail: [ inspetora@sesisp.org.br            ] |
|  Senha:            [ ••••••••••••••                     ] |
|                                                           |
|                     [ ENTRAR NO SISTEMA ]                 |
|                                                           |
|  Dúvidas ou Suporte: codesolutionsteam@gmail.com          |
+-----------------------------------------------------------+
```

### Instruções Passo a Passo:
1. Abra o navegador web no smartphone ou tablet institucional.
2. Digite o endereço do servidor local do sistema.
3. No campo **Usuário / E-mail**, insira o seu login exclusivo fornecido pela administração.
4. No campo **Senha**, digite sua chave de acesso (respeitando letras maiúsculas e minúsculas).
5. Toque no botão verde **"Entrar no Sistema"**.

---

## 2. Tela Principal da Inspetora (Dashboard Mobile)

Após o login, a tela principal exibe a mensagem de boas-vindas (*"Bom dia, Laís!"*) e os botões de ação rápida:

* 🔘 **Nova Contagem:** Inicia o processo de lançamento de presença por sala de aula.
* 🔘 **Ver Contagens:** Exibe o resumo das turmas já contadas na data de hoje e permite correções pontuais.
* 🔘 **Cardápio:** Permite consultar a imagem oficial do cardápio da semana.
* 🔘 **Chat Operacional:** Abre o canal de conversa direta com a sala da Nutrição.
* 🔘 **Perfil:** Exibe os dados cadastrais da sua conta e o botão seguro de encerramento de sessão (*Sair*).

---

## 3. Como Realizar uma Nova Contagem (Sala a Sala)

```
[ PASSO 1: SELEÇÃO ]       [ PASSO 2: QUANTIDADE ]       [ PASSO 3: SUCESSO ]
+---------------------+     +---------------------+     +---------------------+
| ESCOLHA A SALA      |     | 3° ANO E.F - I      |     |                     |
| Data: 28/11/2025    |     |                     |     |       CONTAGEM      |
|                     |     |  QUANTIDADE ALUNOS: |     |      REGISTRADA     |
| [ 1° Ano E.F - I ]  |     |                     |     |     COM SUCESSO!    |
| [ 2° Ano E.F - I ]  |     |   [ - ]  32  [ + ]  |     |                     |
| [ 3° Ano E.F - I ]* |     |                     |     |  [ Próxima Sala ]   |
| [ 4° Ano E.F - I ]  |     |   [ SALVAR CONTAGEM]|     |                     |
+---------------------+     +---------------------+     +---------------------+
```

1. Na tela principal, toque em **"Nova Contagem"**.
2. O sistema listará todas as salas da escola divididas por segmentos (Fundamental 1, Fundamental 2, Ensino Médio e Turmas Especiais).
3. Toque sobre o nome da sala que você está visitando (ex.: **3° Ano E.F**).
4. Na tela de ajuste:
   * O sistema exibe o mostrador com o número de alunos.
   * Você pode tocar no botão **`[+]`** para adicionar alunos ou **`[-]`** para diminuir.
   * Você também pode tocar diretamente no número e digitar o valor total contado.
5. Verifique se o valor está correto e toque no botão **"Salvar Contagem"**.
6. Uma mensagem de sucesso será exibida na tela confirmando o envio.
7. O sistema retorna automaticamente à listagem para que você selecione a próxima sala.
8. As salas já contadas ficam marcadas com um ícone verde de confirmação, evitando contagens em duplicidade.

---

## 4. Como Corrigir uma Contagem do Dia ("Ver Contagens")

Se um aluno chegar atrasado antes das 07:30 e a sala já tiver sido enviada:
1. Acesse o menu e toque em **"Ver Contagens"**.
2. Localize a turma desejada na lista de contagens do dia.
3. Toque no botão **"Alterar"**.
4. Ajuste a quantidade correta de alunos presentes.
5. Toque em **"Atualizar"**. O novo número será refletido imediatamente na tela da Nutricionista.

> [!NOTE]
> Por segurança contábil da escola, não é possível editar ou alterar contagens de dias anteriores. Apenas a data de hoje permite edição.

---

## 5. Utilizando o Chat com a Nutricionista
1. Caso ocorra qualquer imprevisto na contagem (ex.: uma van escolar atrasou, uma turma saiu para passeio externo ou faltaram muitos alunos), toque no botão **"Chat"**.
2. Digite sua mensagem no campo de texto e toque na seta de envio.
3. A Nutricionista receberá o aviso na tela do computador dela em tempo real, sem necessidade de telefonemas ou interrupções na cozinha.
